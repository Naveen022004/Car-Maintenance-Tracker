# Car Maintenance Predictor

A machine learning-powered application that predicts when your vehicle needs maintenance based on its service history and usage patterns.

## Features

- Dashboard with vehicle overview and maintenance alerts
- Detailed vehicle information and service history
- Maintenance prediction using machine learning
- Service record management
- Interactive charts and visualizations
